# 2026-07-12 full deploy at 7567d06

Deployed `main` at `7567d06` to all three delivery paths:

- **Firebase**: `just deploy-firebase` updated functions `githubWebhook` and `adminApi` (Node.js 22, us-central1) and released hosting sites `kexi-380010` (docs) and `scanveil-admin`.
- **scanveil-web**: Cloud Build image `scanveil-web:7567d06` (`sha256:648ee0ee7c6c…`), revision `scanveil-web-00062-x44` serving 100% traffic.
- **scanveil-worker**: Cloud Build image `scanveil-worker:7567d06` (`sha256:4bd88024ba91…`), job generation 38.

Also fixed the Management Console "Scheduled scan update failed: 403 iam.serviceAccounts.actAs" error by granting `roles/iam.serviceAccountUser` on `scanveil-scheduler@kexi-380010.iam.gserviceaccount.com` to `scanveil-web-runtime@kexi-380010.iam.gserviceaccount.com` (applied live with gcloud; codified in Terraform via PR #88). Updating the scheduler job requires actAs on its OAuth token service account even when only `schedule`/`timeZone` change.

Gotcha: `just deploy-firebase` from a git worktree fails with `no value for the following environment variables: GITHUB_APP_ID` because the untracked `.env` / `apps/functions/.env` files are not present in worktrees — copy them from the main checkout first.

Verification: `https://www.scanveil.kexi.dev/` returned 200 and `https://console.scanveil.kexi.dev/` returned 302 (auth redirect) after the rollout.
