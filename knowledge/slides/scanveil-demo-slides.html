SCANVEIL

見張って、直す。

GitHub リポジトリを AI エージェントと OSV がスキャンし、
修正 PR まで届けるセキュリティスキャナー

Kei Nakayama — built on Google Cloud

problem

LLM スキャナーは、そのままでは運用に乗らない

  • ルールベースでは組織独自のルール違反を検出できない
  • LLM は同じ問題を毎回違う表現で報告 → 重複だらけで追跡不能
  • 検出しても、Issue 化・修正は結局人手
how it works

検出 → 追跡 → 修正のループを閉じる

スキャンOSV + AI エージェント
(Antigravity SDK・Gemini 等)
→
SVE-ID 採番RAG で重複抑止
(Firestore Vector Search)
→
結果表示PR 上に表示 (GitHub Checks)
定期スキャンにも対応
→
Fix PRワンクリック生成
resolved 自動判定
feature 01

AI エージェントが組織のルールも見張る

  • Antigravity SDK の AI エージェント（Gemini 等）が PR diff とリポジトリをレビュー
  • 組織のスキャンポリシーをプロンプトに注入
    例:「pnpm の minimumReleaseAge は 1440 以上必須」
  • 汎用スキャンでは見つからない「うちのルール違反」も検出結果として報告
feature 02

RAG で「同じ脆弱性」を同じ ID に

  • 検出結果をベクトル化 → Firestore Vector Search で過去と類似検索
  • 表現が揺れても同じ SVE-ID に束ねて追跡
  • 修正後に再報告されなければ resolved と自動判定
feature 03

検出から修正まで、ワンクリック

  • スキャン結果を PR 上に表示（GitHub Checks）
  • 検出結果から Issue / 修正 PR を AI が生成
